- Updates are easier: FitSuite checks for a new version every time it opens. When there is one, it asks: Update or Not now. Update downloads it, checks it and restarts FitSuite. Your settings and measurements stay as they are.
- After an update, this "What's new" note shows once. You can open it again any time with "What's new" in the bottom-right corner.
- The update setting is now called "Check for updates when FitSuite opens" (Settings → Updates).
