FitSuite 0.2.0 (preview). Not yet tested on a Windows PC; please report anything that does not work as described.

**Download:** `FitSuite-0.2.0-preview-win64.zip`, extract it anywhere, run `FitSuite.exe`. From this version on, FitSuite can update itself (Settings → Updates).

What is new:
- **Calibration in rounds, like an aim trainer:** flicks, micro-adjustments, flicks, tracking and target switching (about 4 minutes). Click to start each round; the next target appears as soon as you hit or miss, a miss makes the target disappear, and every target has a timer. After the calibration you get an aim report for each kind of round.
- The blind test and the quick check use the same fast format (about 2 minutes and 1 minute).
- **First-run setup:** your mouse, your monitor's refresh rate, Raw Accel (FitSuite can download the official Raw Accel 1.7.1 release, check it and start its installer), startup and updates.
- **Updates:** FitSuite checks this page once a day (you can switch that off), downloads a new version only when you click, checks it against its published SHA-256 and restarts into it.
- Warning when a monitor runs below its fastest refresh rate, with a one-click switch (15 seconds to keep it or go back).

`FitSuite.exe` and `FitSuite.exe.sha256` are what the updater uses; the zip is for a first install.
